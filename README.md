# Pantry

This is a React app for managing a personal pantry and finding recipes. Developed by Huu Anh Tran for web-ohjelmointi 1 project

**Live site: https://oggy-huuanh.github.io/wohiproject/

## Features
- My Pantry: show what ingredients are on your pantry
- Browse: Browse all recipes possible
- Recipe page: Show recipe details (how to cook it, what are the ingredients...)
- Favorites: your favorite recipes saved

## Built with
- React + Vite
- React Router: for routing and linking pages together
- React-Bootstrap / Bootstrap: for styling, accessibility and layout
- react-select: for selecting ingredients and filtering recipes
- TheMealDB API: for getting recipe data and information

## How to run it locally
1. `npm install`
2. `npm run dev`
3. Open the address shown in the terminal

## Deployment 
`npm run deploy`
